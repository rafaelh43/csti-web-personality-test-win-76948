## About CSTI Game Personality Test

CSTI Game Personality Test is a browser-based personality quiz built around CS2 and CSGO player behavior. It uses a 35-question flow to estimate your rank tendency, identify likely playstyle traits, and match your answers to one of 15 personality types.

The experience is designed for quick interaction on the web, with multilingual support and a responsive layout that adapts well across screen sizes. Audio and animation effects add presentation polish, making the result flow feel more engaging without changing the core quiz structure.

- 35-question personality test for CS2 and CSGO players
